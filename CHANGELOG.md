# Changelog

## [0.1.0] - 2026-09-02

### Added

- Bounded-memory parsing of single or chunked ChatGPT conversation JSON members.
- Direct ZIP processing with configurable uncompressed-size limits.
- Markdown and typed-code extraction without code execution.
- Deterministic language inference, syntax checks, salvage scores, and explanations.
- SHA-256 exact deduplication with occurrence-level provenance.
- Credential, private-key, email, and macOS home-path review flags.
- Atomic owner-only SQLite indexes and extracted artifacts.
- Clear, hashed, and dropped conversation-title policies.
- Local summary, review, search, and filtered extraction commands.
- Synthetic fixtures, 33 tests, CI, strict typing, and wheel verification.
